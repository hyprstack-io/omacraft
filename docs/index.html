    Install
    
      
    OmaCraft is made for Omarchy 4: Arch Linux, Hyprland 0.53 or newer with Lua config, and the Quickshell-based Omarchy shell. pacman brings everything else.
    
    
    
    
    
      
    1
    From the AUR
    Builds on your machine, so it works on x86_64 and aarch64.
    
        
    yay -S omacraft
    
      
    2
    One-file installer
    Download the .run from Releases, then run it as yourself. It checks the machine, installs with pacman, and adds AlienFlare on an Alienware x15.
    
        
    
        Open Releases
    
      
    3
    From source
    Clone the tag and build the package yourself.
    
        
    
      
    Then check
    Changes nothing. Its output is what a bug report needs.
